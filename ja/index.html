MiaoYan

Mac、iPhone、iPad で使えるローカルの Markdown ノート

MiaoYan は中国語の妙言、言葉を超えた言葉という意味です。

  • 一度の購入で Mac・iPhone・iPad
  • ローカルの Markdown
  • GitHub でオープンソース
  • macOS 12 / iOS 18 以降
App Store で入手 GitHub で見る

書く、読む、プレゼンする

素の Markdown で書き、プレビューで組版を確かめ、2ペインで並べて作業し、ノートをそのままスライドにできます。

シンタックスハイライト付きの素の Markdown で、見出し、リンク、コードがひと目で区別できます

iPhone と iPad

同じ App Store の購入で iPhone と iPad でも使え、Mac と同じ iCloud Drive フォルダを開きます。

App Store で入手

MiaoYan を選ぶ理由

ローカルファースト

Markdown ファイルは自分で選んだフォルダに保存され、MiaoYan はノートのデータを集めません。デバイス間の同期は iCloud Drive や Nutstore などのファイル同期ツールに任せられます。

集中

フォルダ、ノート一覧、エディタの3ペイン構成で、書くのに必要なものがひとつの画面に揃います。ダークモード、集中して書ける画面、キーボードショートカットを内蔵し、管理するプラグインはありません。

ネイティブ

Electron ではなく Swift 6 でネイティブに開発しています。2ペインモードはリアルタイムプレビューと 60fps の双方向スクロール同期で、Markdown の編集に集中できます。

必要十分

双方向リンクとバックリンク、LaTeX、Mermaid、バージョン履歴、自動整形、CLI、Markdown プレゼンテーションで、書くまわりの作業もこなせます。

MiaoYan が向いている人

Typora と比べると

MiaoYan は WYSIWYG ではなく、素の Markdown 編集と独立したプレビューを保っています。ソースファイルを直接扱いながら、すぐに見た目も確かめたい人に向いています。

Obsidian と比べると

MiaoYan は Electron を使わず、プラグインのエコシステムを中心にもしていません。ローカルファイルと絞り込んだ内蔵機能で、ネイティブで軽いアプリを求める人に向いています。

よくある質問

買い切りですか、サブスクリプションですか？

サブスクリプションやアプリ内課金のない、一度の買い切りです。同じ Apple アカウントの Mac、iPhone、iPad でそのまま使えます。

どのバージョンを入れればいいですか？

App Store 版がおすすめです。一度の購入で Mac、iPhone、iPad のすべてで使え、どれも同じ iCloud Drive フォルダを開き、アップデートも自動です。Mac 版のソースコードは GitHub で公開しています。

ノートはどこに保存されますか？

自分で選んだフォルダに、普通の .md ファイルとして保存されます。MiaoYan はノートのデータを集めず、ほかのツールに移るときもフォルダごと持っていけます。

Mac と iPhone の間でどう同期しますか？

フォルダを iCloud Drive に置けば、Mac、iPhone、iPad が同じノートを開きます。Mac では Nutstore などのファイル同期ツールも使えます。

どんな Markdown に対応していますか？

GitHub Flavored Markdown に加えて、LaTeX、Mermaid、PlantUML、Markmap、双方向リンクとバックリンク、--- で区切るスライドに対応しています。

動作環境は？

Mac は macOS 12 以降、iPhone と iPad は iOS 18 以降が必要です。
