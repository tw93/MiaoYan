用 Markdown 写每日笔记，做法是一天一个纯文本文件，文件名用 ISO 日期，比如 `2026-11-14.md`，再按年份放进文件夹。这个名字在任何文件浏览器里都按时间排序，在妙言里直接成为笔记标题，也能当 wikilink 的目标，一个命名同时管了三件事。再加一个在 front matter 里写 `date` 的简短模板，用几行 shell 创建当天的文件，更早的内容靠搜索找回。妙言在 V4.9.0 里没有每日笔记命令，也没有模板设置，下面讲的是一套命名约定加一个脚本，不是内置功能。

## 用日期给文件命名

文件名写成 `YYYY-MM-DD.md`。年在前，月、日补零到固定宽度，按字母排序和按时间排序就是同一个顺序，写成 `14-11-2026` 或 `Nov 14` 的话，会按日或者按月份英文名排，条目就散开了。

日期可以让 shell 生成，`date +%F` 会输出 `2026-11-14` 这样的当天日期，macOS 自带的 `date` 就能用。要昨天的日期，macOS 上写 `date -v-1d +%F`，Linux 的 GNU `date` 写 `date -d yesterday +%F`。

在妙言里，笔记标题就是去掉扩展名的文件名，所以 `2026-11-14.md` 在列表里显示为「2026-11-14」，文件内部不用再重复写一遍。

## 按年份放进文件夹

一年一个文件夹，每个列表都不会太长：

```text
MiaoYan/
  Journal/
    2025/
      2025-12-31.md
    2026/
      2026-11-13.md
      2026-11-14.md
```

也可以再按月分文件夹，但搜索一步就能到的时候，多这一层很少用得上，[本地优先的 Markdown 笔记](/zh/blog/local-first-markdown-notes/)里也是主张笔记库保持浅层。Obsidian 的每日笔记插件直接支持这个做法，它的帮助页说日期格式写成 `YYYY/MMMM/YYYY-MMM-DD`，插件就会自动建好子文件夹。

## 一个简短的模板

模板短到你不会想跳过它：

```markdown
---
date: 2026-11-14
---

## 计划

## 记录

## 链接
```

`date` 和文件名重复，这是有意的，读元数据的脚本不用去解析文件名，笔记被改名或移动之后也还能看出是哪一天。妙言会在预览和导出里隐藏开头的 front matter，编辑器里仍然显示，规则见 [Markdown front matter](/zh/blog/markdown-front-matter/)。「计划」里用 `- [ ]` 写待办（见[任务列表](/zh/blog/markdown-task-lists/)），「记录」随便写，「链接」放当天用到的 wikilink，某个部分连续一周都空着，就从模板里删掉。

## 在终端里创建今天的文件

这个脚本只在文件不存在时才创建今天的文件，然后打印路径：

```bash
#!/bin/bash
NOTES="${MIAOYAN_PATH:-$HOME/Documents/MiaoYan}"
today=$(date +%F)
file="$NOTES/Journal/$(date +%Y)/$today.md"
mkdir -p "$(dirname "$file")"
[ -e "$file" ] || printf -- '---\ndate: %s\n---\n\n## 计划\n\n## 记录\n\n## 链接\n\n' "$today" > "$file"
echo "$file"
```

存成 `today`，加上可执行权限并放进 `PATH`。`MIAOYAN_PATH` 是 `miao` 命令行读取的同一个变量，笔记库不在 `~/Documents/MiaoYan` 的话，在 shell 配置里设一次就行。`[ -e ]` 这一句让第二次运行没有副作用，已有的文件不会被动。妙言通过 macOS 的文件系统事件监视文件夹，新文件会自己出现在列表里，用 `open -a MiaoYan "$(today)"` 可以直接打开。

### 用 miao 命令

`miao` 也能创建笔记：

```bash
miao new "$(date +%F)" "## 计划"
```

有两点要知道。`miao new` 是通过 `miaoyan://new/` 地址把标题和正文交给应用，文件会建在应用侧栏当前选中的文件夹里，命令本身没有指定文件夹的参数，只有侧栏里正好选中 `Journal/2026` 时才会建在那里。另外同名文件已经存在时，妙言不会打开它，而是新建 `2026-11-14 1.md`，再下一次是 `2026-11-14 2.md`，一天里运行两次就有两个文件。第二个参数整个成为正文，不会自动加标题。

所以创建当天的文件用上面的脚本更合适，`miao` 适合做其余的事，`miao open 2026-11-14` 按标题打开某天，`miao cat 2026-11-14` 打印内容，`miao list Journal/2026` 列出一年的文件，命令的细节见[在终端里使用 Markdown 笔记](/zh/blog/markdown-notes-from-terminal/)。

## 把每天串起来

在「链接」里写 `[[2026-11-13]]` 指向昨天，或者写 `[[项目计划]]` 指向当天碰到的事。wikilink 按标题精确匹配，匹配范围是整个笔记库，所以 `[[2026-11-13]]` 在任何文件夹里都有效，年份文件夹不会出现在链接里。反向链接是反过来的视角，用 Command Option I 打开文档属性面板，「反向链接」一行会列出所有链接到当前笔记的笔记，项目笔记因此能看到哪几天提过它。写法和限制见 [Wikilink 与反向链接](/zh/blog/wikilinks-and-backlinks/)，反复出现的想法值得单独成一篇笔记的话，下一步可以看[用 Markdown 笔记做卡片盒](/zh/blog/zettelkasten-markdown-notes/)。

## 之后怎么找

日期名只能回答「14 号我做了什么」，其余的靠搜索。

**在妙言里。** Command / 跳到搜索框，输入的每个词都要出现在标题或正文里，可以分在两处。输入 `2026-11` 能通过标题找出十一月的每一天，输入 `roadmap` 能找出提到它的日子，最多列出 100 条结果。

**列表按标题排序。** 在「视图」菜单的「排序方式」里有修改日期、创建日期和标题，另外有升序和降序。日记选「标题」加「降序」，最新的日期在最上面。改动旧的一天会让修改日期的排序整个重排，创建日期来自文件元数据，复制或同步之后可能变掉。置顶的笔记不管哪种排序都留在列表上方。

**在终端里。** ripgrep 读完整本日记很快：

```bash
rg -n -F -- '- [ ]' Journal           # 所有未完成的待办，带文件和行号
rg -l -i roadmap Journal/2026         # 提到某个词的日子
rg -l -F 'date: 2026-11' Journal      # 按 front matter 找出十一月的每一天
```

`miao search <关键词>` 搜索整个笔记库，输出 `路径:行号:文本`，装了 ripgrep 时是固定字符串搜索，没装就退回到 `grep`。

## 让习惯轻一点

日记多半是死在模板上，不是死在工具上。状态差的那天写一行就够，空文件什么也证明不了，一行字至少说明你来过。旧的日子除了改错字就别动，值得有后续的内容挪到单独起标题的笔记里，再从当天链过去。

妙言给每篇笔记保留最多 20 个版本，用 Command Shift H 恢复，误删当天的文字时能救回来，它覆盖不到什么见[笔记版本历史](/zh/blog/markdown-note-version-history/)。日记所在的文件夹也值得交给 Time Machine 或 git。

## Obsidian 更合适的时候

Obsidian 帮助站介绍了核心插件「每日笔记」，它会打开以当天日期命名的笔记，默认格式是 `YYYY-MM-DD`，不存在就创建，可以用命令面板里的命令或快捷键触发，还可以套用带 `{{date:YYYY-MM-DD}}` 的模板文件，并放进你指定的文件夹。想要按一个键就打开已经套好模板的今天，这一点妙言做不到。两个应用读的都是 `YYYY-MM-DD` 命名的纯 Markdown 文件，同一个文件夹在两边都能打开，对比见 [Mac 上的 Obsidian 替代品](/zh/blog/obsidian-alternative-mac/)。

妙言的 Mac 版在 [GitHub](https://github.com/tw93/MiaoYan) 开源，[App Store](https://apps.apple.com/app/id6759252269) 版本一次购买覆盖 Mac、iPhone 和 iPad。

## 出问题时怎么查

- **一天出现两个文件。** 多半是 `miao new` 运行了两次，或者同步服务生成了冲突副本，找 `2026-11-14 1.md` 这样的文件，合并文字后删掉多余的那个。
- **点日期链接跳到了搜索。** 有两篇笔记同名，比如工作日记和私人日记里都有 `2026-11-14.md`，只留一个日记文件夹，或者加后缀写成 `2026-11-14 work`。
- **日期排序错乱。** 某个文件的月或日是一位数，全部补零。
- **脚本把文件写到了别处。** 没设 `MIAOYAN_PATH`，而 `~/Documents/MiaoYan` 又不是你的笔记库，把它设成你在应用里选的那个文件夹。

## 常见问题

### 妙言有每日笔记功能吗？

没有，V4.9.0 里既没有打开今天笔记的命令，也没有模板设置，上面的命名约定加脚本多一步就能达到同样的效果。

### 按新建时能自动套上模板吗？

不能直接做到。手动的办法是留一篇叫「Template」的笔记，按 Command D 制作副本得到「Template Copy」，再用 Command R 重命名，不过脚本更快。

### 周记或月记怎么做？

用同样的写法，比如 `2026-W46.md` 或 `2026-11.md`，在汇总里链接到具体的日子，`date +%G-W%V` 会输出 ISO 周数。
