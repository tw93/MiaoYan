在 Mac 上用键盘写 Markdown，其实是两层快捷键叠在一起，macOS 的文本系统让所有原生文本框共用一套移动和删除按键，应用再在上面加自己的菜单快捷键。本文把两层都列出来，macOS 这层来自苹果的「Mac 键盘快捷键」页面，妙言这层来自 V4.9.0 的菜单，加上应用在代码里处理的按键。表格里 ⌘ 是 Command，⇧ 是 Shift，⌥ 是 Option，⌃ 是 Control。

## 任何文本框都能用的 macOS 按键

妙言的编辑器是原生文本视图，下面这些不用任何设置就能用，备忘录、邮件和文本编辑里也一样。

| 按键 | 作用 |
| --- | --- |
| ⌥ 左 / 右箭头 | 移到上一个词的开头，或下一个词的末尾 |
| ⌘ 左 / 右箭头 | 移到当前行的开头或末尾 |
| ⌘ 上 / 下箭头 | 移到文稿的开头或末尾 |
| ⌥ Delete | 删除插入点左边的一个词 |
| Fn Delete 或 ⌃ D | 删除插入点右边的字符 |
| ⌃ H | 删除插入点左边的字符 |
| ⌃ A / ⌃ E | 移到行或段落的开头或末尾 |
| ⌃ F / ⌃ B | 向前或向后移一个字符 |
| ⌃ N / ⌃ P | 向下或向上移一行 |
| ⌃ K | 剪切从插入点到段落末尾的文字 |
| ⌃ Y | 粘贴 ⌃ K 剪切的内容 |
| ⌃ T | 交换插入点两侧的字符 |
| ⇧ 加移动键 | 按同样的幅度扩展选区 |
| ⌘ Z / ⇧⌘ Z | 撤销和重做 |

⌃ K 有个坑，苹果说它剪切到一个只有原应用能用的剪贴板里，所以 ⌘ V 粘不出来，要用 ⌃ Y。

妙言的编辑器遇到带 Option 或 Control 的组合会直接放行，上面这些键一个都不会被覆盖。

## 妙言：格式

格式菜单会把选中的文字包起来，没有选中就插入一对空标记并把光标放在中间，它们作用在编辑器上，预览模式下没有效果。

| 按键 | 菜单项 | 中文菜单 | 写入 |
| --- | --- | --- | --- |
| ⌘ B | Bold | 粗体 | `**text**` |
| ⌘ I | Italic | 斜体 | `*text*` |
| ⌘ U | Underline | 下划线 | `<u>text</u>` |
| ⇧⌘ X | Deleteline | 删除线 | `~~text~~` |
| ⌘ K | Link | 链接 | 一个链接 |
| ⌘ T | Todo | 待办 | `- [ ] `，或切换 `[ ]` 和 `[x]` |
| ⌘ E | Inline Code | 行内代码 | 反引号 |
| ⇧⌘ E | Code Block | 代码块 | 围栏代码块 |
| ⌘ ] / ⌘ [ | Shift Right / Shift Left | 右移 / 左移 | 缩进或取消缩进 |
| ⇧⌘ L | Format（编辑菜单） | 文档排版 | 整理整篇笔记 |

粗体、斜体、下划线和删除线只会包裹不会切换，再按一次 ⌘ B 会多包一层，见[粗体、斜体和删除线](/zh/blog/markdown-bold-italic-strikethrough/)。「清理排版」没有快捷键，标题、引用和列表也没有，`#`、`>` 和 `- ` 要自己敲。

### 编辑器里直接处理的按键

这些按键不在任何菜单里，是应用在代码里处理的。

| 按键 | 作用 |
| --- | --- |
| Tab / ⇧ Tab | 给当前行或所有选中行缩进或取消缩进两个空格，数字列表后面是三个 |
| Return | 延续列表，符号列表照旧，数字列表接下一个数字，待办接一个未勾选的，空标记上再按会删掉标记 |
| ⇧ Return | 只换行，不延续列表 |
| ⌘ Delete | 编辑器有焦点时删到行首 |
| ⌘ S | 立刻写入待保存内容并提示「已保存」 |
| Esc | 关闭搜索栏 |

### Tab 快速输入

输入斜杠加名字再按 Tab 就会插入模板，格式菜单的「Tab 快捷输入」里列着这些。

| 输入后按 Tab | 插入 |
| --- | --- |
| `/table` | 三列的表格模板 |
| `/task` | 两个未完成和一个已完成的任务 |
| `/img`、`/video` | `<img>` 或 `<video>` 标签，光标在 `src` 里 |
| `/mermaid`、`/plantuml`、`/markmap` | 带示例图的围栏代码块 |
| `/fold` | `<details>` 折叠块 |
| `/time` | 当前时间，格式 `yyyy-MM-dd HH:mm:ss` |

这些模板里的占位文字在 V4.9.0 里是中文，英文笔记里要自己替换。每种块渲染出什么见 [Markdown 里画 Mermaid 图](/zh/blog/mermaid-diagrams-in-markdown/)。

## 改快捷键

苹果给的步骤是，打开系统设置，在侧边栏点键盘，再点键盘快捷键，选左边的 App 快捷键，点添加，在应用程序弹出菜单里选应用，菜单标题要和应用里显示的完全一致，然后按下想要的组合键并点完成。嵌套菜单用 `->` 连接，中文界面下要写中文标题，比如 `格式->粗体`。苹果还写了两条限制，已经被别的命令占用的快捷键不会生效，也只能给已有的菜单命令改快捷键，所以 Tab、Return、⇧⌘ H 这些代码里处理的键没法这样改。

## 常见问题

### Mac 上 Markdown 加粗的快捷键是什么？

妙言里是 ⌘ B，会把选中的文字包进 `**`，别的编辑器不一定一样。
