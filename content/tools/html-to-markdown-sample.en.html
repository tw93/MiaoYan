Install Homebrew on a Mac

Homebrew is a package manager for the Mac. Once it is in, one command installs an app; the details are on its site.

  1. Open Terminal and paste the command below
  2. Type your login password when asked
  3. Run brew doctor when it finishes
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Everyday commands

CommandWhat it does
brew installInstall an app
brew upgradeUpgrade everything
brew cleanupRemove old versions

On a Mac with Apple silicon, Homebrew lives in /opt/homebrew.
