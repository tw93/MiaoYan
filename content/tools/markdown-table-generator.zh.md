## 粘贴进来会怎样

在 Excel、Numbers 或 Google Sheets 里选中单元格复制，点一下网格的第一格再粘贴，整张表就换成复制的内容，点中间的某一格粘贴，会从那一格往右下填，行和列不够时自动补上，填错了点撤销就能回去。CSV 和 TSV 文件可以直接拖进来，已有的 Markdown 表格整段粘贴，各列的对齐方式也会一起带过来。

Markdown 表格有自己的限制，转换时单元格里的换行会写成 `<br>`，竖线转义成 `\|`，合并的单元格拆开，内容留在第一格。第一行总是表头，写法的细节见 [Markdown 表格：对齐、竖线与单元格换行](/zh/blog/markdown-tables/)，从 Excel 转换的几种办法见 [Excel 转 Markdown 表格，粘贴转换和检查](/zh/blog/excel-to-markdown-table/)。

## 常见问题

### 表格最多能放多大？

网格最多 500 行、30 列，从 Excel 或 CSV 粘贴的内容超出时，多出的行和列不会放进来，状态栏会说明。

### 中文为什么按两个字符宽对齐？

终端和 Prettier 都把一个汉字算成两个字符宽，这里也这样补空格，在中英文等宽的字体里打开，各列的竖线就能对齐，不需要对齐时把对齐各列关掉，输出就不再补空格。

### 能合并单元格吗？

Markdown 表格不能合并单元格，粘贴进来的合并单元格会拆开，内容留在第一格，确实需要合并，只能在笔记里写 HTML 的 `<table>`，用 `colspan` 和 `rowspan` 合并。

### 表格会保存吗？

最后编辑的表格存在这个浏览器里，下次打开还在，换了浏览器或者清掉网站数据就没了。粘贴的数据只在浏览器里转换，不会发到服务器。
