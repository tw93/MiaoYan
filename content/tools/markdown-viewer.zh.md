## 复制到公众号

写完点复制到公众号，到公众号后台的图文编辑器里粘贴，标题、引用、列表、表格和代码块会带着妙言的样式过去。公众号会丢掉样式表和 class，所以复制时把每个元素的样式都写在了它自己身上，引用的竖条改成左边框，任务列表的勾选框换成 ☐ 和 ☑，代码保留缩进和换行，Mermaid 图转成图片。公众号正文里指向其他网站的链接点不开，这些链接会变成右上角的编号，地址统一列在文末的参考链接里，公众号自己的文章链接保持原样，公式目前按 `$...$` 的源码复制过去。

要交给用 Word 的人，点下载 Word，得到一份按同样样式排好的 .docx，公式变成 Word 公式，详细的说明在 [Markdown 转 Word](/zh/tools/markdown-to-word/)。

## 写起来顺手的地方

快捷键和妙言一样，`⌘B` 加粗、`⌘I` 斜体、`⌘K` 链接、`⌘E` 行内代码、`⇧⌘E` 代码块，`⌘S` 把 Markdown 存成文件，Windows 上把 ⌘ 换成 Ctrl。列表和引用里按回车会接着写下一项，空着再按一次就结束。两边按段落对齐滚动，左边滚到哪一段，右边就停在哪一段，反过来也一样。手机宽度按 375 像素排版，和公众号文章在手机上的宽度差不多，工具栏最右边的按钮可以全屏写，底部的字数和妙言的算法一样，每个汉字算一个，英文按词算。

## 和妙言的预览有多像

右边用的是妙言预览同一套样式表，代码高亮、公式和 Mermaid 也是 App 里那几份文件，所以字体、行距、表格和代码块都和笔记里看到的一样。不同的是这里用 markdown-it 解析 Markdown，App 里用的是 cmark-gfm，两者都遵循 CommonMark 和 GitHub 的表格、删除线、任务列表写法，只有很少见的写法结果会有差别。

## 常见问题

### 要收费吗，文件会上传吗？

不收费，也不用注册，打开的文件只在浏览器里读，不会发到服务器，最后一次的内容存在这个浏览器里，下次打开还在。

### 支持哪些写法？

标题、列表、引用、表格、任务列表、删除线、代码块和代码高亮都支持，公式用 `$...$` 和 `$$...$$`，写在 mermaid 代码块里的图会画出来。Mermaid 的写法见 [Markdown 里画 Mermaid 图](/zh/blog/mermaid-diagrams-in-markdown/)。

### 图片为什么显示不出来？

网页读不到电脑上的文件，`images/a.png` 这种本地路径的图片不会显示，只有以 `https://` 开头的网络图片能显示。在妙言里打开同一个文件，本地图片照常显示。
