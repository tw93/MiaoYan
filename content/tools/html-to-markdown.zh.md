## 它能转哪些东西

从网页、Word 或 Google 文档里复制一段内容，在左边粘贴，右边就是写好的 Markdown，标题变成 `#`，列表、引用和表格照原来的层级写出来，链接和图片留下地址，代码块会带上它的语言，比如 `language-bash` 写成 `` ```bash ``。没点进左边时直接按 `⌘V` 也行，第一次粘贴会替换掉示例，之后粘贴的内容插在光标处，左边改了什么右边跟着变，右边也可以接着手改。

手上是文件的话，点打开文件或者直接拖进来，.docx 会在浏览器里读出标题、列表、表格和加粗，.html 按网页处理。Google 文档复制出来的内容整段包在一个加粗里，加粗和斜体写在样式上，Word 的列表复制出来是一行行前面带着圆点的段落，这几种都会还原成正常的 Markdown。

## 哪些转不过来

Markdown 里只能放图片的地址，所以 Word 里插入的图片、截图粘贴进文档的图片带不过来，网页上的图片会保留原来的网址。字号、颜色、字体、居中这类排版信息会去掉，合并过的单元格只占一格，公式只保留能复制出来的文字，转完扫一眼表格和公式最稳妥。

## 常见问题

### 要收费吗，内容会上传吗？

不收费，也不用注册，转换在浏览器里完成，粘贴的内容和打开的文件都不会发到服务器，左边显示的网页图片会从它原来的网站加载。

### 和妙言里粘贴的效果一样吗？

一样，这里用的是妙言 Mac 版粘贴网页内容时的同一套转换，逐行照着它的源码写成网页版，同一段网页两边转出来一字不差。妙言只在内容里有标题、列表、表格、引用或代码块时才转，普通的一句话照原文粘贴；这个页面每次都转，另外还多认了 Google 文档的整段加粗、Word 的列表和图片下面的图注。

### 转出来的 Markdown 能直接用吗？

能，复制以后贴进妙言、GitHub、Obsidian 这类支持 Markdown 的地方就行，也可以下载成 .md 文件，文件名取自打开的文件或者第一个标题。想先看看排出来的样子，可以贴到 [Markdown 在线预览](/zh/tools/markdown-viewer/)里。
