## How to install

Install [NetNewsWire](https://netnewswire.com/) first, then click Install in NetNewsWire above. The browser asks to open NetNewsWire, and NetNewsWire then asks to Install Theme. Once it is in, choose MiaoYan under Article Theme in the Appearance settings.

## What it changes

Body text sits at a 1.7 line height with 0.5px tracking, so Chinese paragraphs no longer feel cramped. Links stay a classic blue, feed names take a green accent, feed avatars are round and code is set in SF Mono. Light mode is #444444 text on #FDFDFD and dark mode is #DCDCDC on #1A1A1A, following the system. The article in the preview above is a post from the [MiaoYan blog](/blog/), and this is how it reads in NetNewsWire. Its feed is `https://miaoyan.app/blog/feed.xml`.

## FAQ

### Nothing happens when I click Install. What now?

NetNewsWire is probably not installed on this device yet; install it and click again. You can also download MiaoYan.nnwtheme.zip, unzip it and double-click MiaoYan.nnwtheme.

### Does it work on iPhone and iPad?

Yes. NetNewsWire for iPhone and iPad reads the same theme and the same install link, so tapping Install in NetNewsWire on the phone puts it there.

### Which font does the body use?

The theme asks for TsangerJinKai first, but NetNewsWire loads an article with the article's own address as its base, so the font file inside the theme cannot be read. It is used only when TsangerJinKai is installed in the system; otherwise the text is set in PingFang SC, which is what the preview shows.

### Can I change how it looks?

Yes. The theme is free and open source on [GitHub](https://github.com/tw93/MiaoYan-NetNewsWire-Theme), its stylesheet and template under the MIT licence; in the unzipped download, colours, sizes and line height are in the stylesheet.css inside MiaoYan.nnwtheme, and double-clicking MiaoYan.nnwtheme again installs your edit.
