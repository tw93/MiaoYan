# 介绍妙言

妙言是一个轻灵的 Markdown 笔记本，每篇笔记都是一个普通的 `.md` 文件，在 Mac 上按 `⌘3` 可以在源码和排好版的样子之间切换，按 `⌘\` 可以左边写、右边看。

## 先看看效果

一张小表格：

| 打开妙言 PPT | `⌥⌘P` |

## 在 Mac 上试试这三件事

1. 按 `⌘N` 新建一篇笔记，先写标题，回车后接着写正文
2. 在正文里输入 `/mermaid` 再按 `Tab`，流程图模板就出来了，`/table`、`/task`、`/fold` 也是这样用
3. 打开同一个文件夹里的「妙言 PPT」，按 `⌥⌘P` 看看用 Markdown 写的演示文稿

还不会 Markdown 的话，打开同一个文件夹里的「妙言 Markdown 语法指南」，按 `⌘\` 分栏，左边是写法，右边是效果，标题、代码、图表、脚注都在里面。

## 在 iPhone 和 iPad 上接着写

[iPhone 和 iPad 版](https://apps.apple.com/cn/app/miaoyan/id6759252269)打开同一个 iCloud 云盘文件夹就行，Mac 上写的笔记在手机上接着看、接着写。每篇笔记都存在你自己的文件夹里，存放位置可以在设置中查看和修改。

<details>
<summary>Mac 上的快捷键</summary>

#### 窗口操作

- `⌘1` - 收起展开目录
- `⌘2` - 收起展开文档列表
- `⌘3` - 切换编辑和预览
- `⌘4` - 切换到演示模式
- `⌘5` - 切换大纲目录（TOC）
- `⌘\` - 切换分栏编辑预览
- `⌥⌘0` - 显示主窗口
- `⌥⌘M` - 全局唤起/隐藏妙言

#### 文档操作

- `⌘N` - 新建文档
- `⌘R` - 重命名文档
- `⌘D` - 制作副本
- `⌘O` - 以单独模式打开文件或文件夹
- `⌘⌫` - 将文档移到废纸篓
- `⇧⌘N` - 新建文件夹
- `⇧⌘L` - 自动排版
- `⌥⌘R` - 在 Finder 中显示
- `⌥⌘I` - 显示简介
- `⌥⌘P` - 启动妙言 PPT 预览

</details>

<details>
<summary>更多用法</summary>

- 按下 `⌘5`，或在预览模式下把鼠标移到右上角细长把手，就能唤出目录，文档里有两个以上的标题就会自动生成大纲
- 菜单栏 `格式 > Tab 快捷输入` 会列出所有片段，内置指令包括 `/time`、`/table`、`/img`、`/video`、`/markmap`、`/mermaid`、`/plantuml`、`/fold`、`/task`
- 粘贴纯文本后按 `⇧⌘L` 一键整理标题、列表与空行
- 在列表或任务项中按一次回车会继续当前项目，两次回车则回到普通段落
- 妙言 PPT 只对包含 `---` 分隔符的文档生效，演示中按回车预览大纲，按 `Esc` 退出，复杂用法参考 [Reveal](https://revealjs.com/markdown/) 文档

</details>

## 为什么做妙言

之前尝试过众多笔记应用（为知笔记、印象笔记、Ulysses、Quiver、MWeb、Bear、Typora），始终没找到一款趁手的 Markdown 工具，于是有了做妙言的想法。

本职工作是前端开发，会一点 iOS，爱折腾，借妙言探索 Swift 和 macOS 开发，顺便做一个自己喜欢的工具。
