MiaoYan을 쓰는 이유

로컬 우선

마크다운 파일은 직접 고른 폴더에 저장되고, MiaoYan은 노트 데이터를 수집하지 않습니다. 기기 간 동기화는 iCloud Drive나 Nutstore 같은 파일 동기화 도구에 맡기면 됩니다.

집중

폴더, 노트 목록, 편집기로 이루어진 3단 구성으로 쓰는 데 필요한 것이 한 화면에 모입니다. 다크 모드, 방해 없는 글쓰기, 키보드 단축키가 들어 있고 관리할 플러그인은 없습니다.

네이티브

Electron이 아닌 네이티브 앱입니다. 분할 모드는 실시간 미리보기와 양방향 스크롤 동기화로 마크다운 편집에 집중하게 해 줍니다.

충분한 기능

양방향 링크와 백링크, LaTeX, Mermaid, 버전 기록, 자동 서식, CLI, 마크다운 프레젠테이션으로 글쓰기에 필요한 부가 작업까지 두루 뒷받침합니다.

MiaoYan이 맞는 사람

Typora와 비교하면

MiaoYan은 WYSIWYG 대신 순수 마크다운 편집과 별도의 미리보기를 유지합니다. 원본 파일을 직접 다루면서 결과도 바로 보고 싶은 사람에게 맞습니다.

Obsidian과 비교하면

MiaoYan은 Electron을 쓰지 않고, 플러그인 생태계를 중심에 두지도 않습니다. 로컬 파일과 꼭 필요한 내장 기능을 갖춘 가벼운 네이티브 앱을 원하는 사람에게 맞습니다.

자주 묻는 질문

일회성 구매인가요, 구독제인가요?

구독이나 인앱 결제가 없는 일회성 구매입니다. 동일한 Apple 계정의 Mac, iPhone, iPad에서 모두 사용할 수 있습니다.

오픈 소스 버전과 App Store 버전은 무엇이 다른가요?

Mac 버전은 무료 오픈 소스로, brew install --cask miaoyan으로 설치하거나 GitHub Releases에서 받을 수 있습니다. iPhone과 iPad 버전은 오픈 소스가 아니어서 Mac 버전과 함께 App Store에서 제공합니다. 한 번 구매로 세 기기 모두에서 쓸 수 있고, 같은 iCloud Drive 폴더를 열며 업데이트도 자동입니다. 두 Mac 버전의 글쓰기 기능은 같으므로, Mac에서만 쓴다면 오픈 소스 버전으로 충분하고, iPhone과 iPad에서도 이어 쓰려면 App Store 버전을 고르세요.

노트는 어디에 저장되나요?

직접 고른 폴더에 일반 .md 파일로 저장됩니다. MiaoYan은 노트 데이터를 수집하지 않으며, 다른 도구로 옮길 때도 폴더째 가져가면 됩니다.

Mac, iPhone, iPad 사이에서 어떻게 동기화하나요?

폴더를 iCloud Drive에 두면 Mac, iPhone, iPad가 같은 노트를 엽니다. Mac에서는 Nutstore 같은 파일 동기화 도구도 쓸 수 있습니다.

어떤 마크다운을 지원하나요?

GitHub Flavored Markdown과 함께 LaTeX, Mermaid, PlantUML, Markmap, 양방향 링크와 백링크, ---로 나누는 슬라이드를 지원합니다.

실행 환경은 어떻게 되나요?

Mac은 macOS 12 이상, iPhone과 iPad는 iOS 18 또는 iPadOS 18 이상이 필요합니다.
