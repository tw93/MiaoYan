为什么选择妙言

本地

Markdown 文件保存在你选择的本地文件夹，不收集笔记数据。跨设备时，可交给 iCloud 云盘、坚果云或你熟悉的文件同步工具。

专注

三栏经典布局将目录、笔记与编辑器融为一体。支持深色模式、无干扰写作和常用快捷键，无需维护复杂插件系统。

原生

使用 Swift 6 原生开发，不依赖 Electron。分栏模式提供实时预览与 60fps 双向滚动同步，丝滑跟手。

称手

内置双向链接与反向链接、LaTeX 公式、Mermaid 图表、版本历史、自动排版与命令行工具，也能一键开启幻灯片演示。

妙言适合谁

和 Typora 相比

妙言不做所见即所得编辑，而是保留纯 Markdown 源码编辑与独立预览。更适合希望直接掌控源文件，又需要即时预览的人。

和 Obsidian 相比

妙言没有 Electron 运行时，也不以插件生态为中心。更适合想要原生、轻量、纯本地文件和开箱即用核心功能的人。

常见问题

是买断制还是订阅制？

一次性买断，终身使用，没有订阅或内购。同一次购买可在登录同一 Apple 账户的 Mac、iPhone 和 iPad 上完整使用。

该装哪个版本？

推荐 App Store 版：一次购买覆盖 Mac、iPhone 和 iPad，通过 iCloud 云盘无缝同步，且自动更新。Mac 版源码在 GitHub 开源透明。

笔记存在哪里？

就在你选定的文件夹里，每篇都是普通的 .md 文件，妙言不收集笔记数据，以后换工具时整个文件夹带走就行。

Mac、iPhone 和 iPad 之间怎么同步？

把笔记文件夹放在 iCloud 云盘里，Mac、iPhone 和 iPad 打开的就是同一份笔记，Mac 上也可以用坚果云等文件同步工具。

支持哪些 Markdown 语法？

GitHub 风格的 Markdown，加上 LaTeX 公式、Mermaid、PlantUML 和 Markmap 图表、双向链接，以及用 --- 分页的演示模式。

需要什么系统？

Mac 需要 macOS 12 及以上，iPhone 和 iPad 分别需要 iOS 18 与 iPadOS 18 及以上。
