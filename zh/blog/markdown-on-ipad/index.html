iPad 上写 Markdown：文件、同步和编辑器

笔记管理2026年10月19日约 6 分钟

在 iPad 上写 Markdown，选一个能直接编辑 .md 文件、而且文件放在「文件」App 看得见的文件夹里的应用，再把这个文件夹放进 iCloud Drive，Mac 上就能看到同一批笔记。妙言的 iPad 版就是这个思路，它打开的是 Mac 在用的那个文件夹，三栏显示资料库，笔记先以阅读方式打开，点编辑按钮才进入编辑。它更像带编辑器的阅读器而不是完整的写作环境，下面几条限制要对照你的写法看一下。

iPad 上的 Markdown 工作流需要什么

日常用起来是否顺手，取决于四件事。

  • 文件放在哪。 笔记应该是文件夹里的普通文件，而不是应用数据库里的记录，这样「文件」App、备份和别的编辑器都够得着。
  • 怎么输入。 外接键盘，或者屏幕键盘加格式辅助，各家差别很大。
  • 预览。 有的并排显示，有的在编辑和预览之间切换。
  • 同步。 把文件夹送到其他设备的那个东西，只用苹果设备的话通常是 iCloud Drive。

第一条和最后一条是以后最容易踩的，困在某个应用私有存储里的笔记很难带走，没同步完的文件夹看起来就像笔记丢了。

妙言在 iPad 上

妙言官网写的是同一次 App Store 购买可以用在 iPhone 和 iPad 上，打开和 Mac 相同的 iCloud Drive 文件夹。买断一次，没有订阅和内购，iPhone 和 iPad 版要求 iOS 或 iPadOS 18 及以上。

4.5.0 版的 iPad 版是这样的：

  • 宽屏下是三栏布局，侧边栏有「笔记」（最近的笔记）、「全部笔记」、你的文件夹和「回收站」，中间是笔记列表，右边是笔记本身。
  • 笔记先以阅读视图打开，点编辑按钮进入 Markdown 编辑器，点「完成」结束，编辑器会显示保存状态，先是「保存中」再是「已保存」。
  • 新建、重命名、移动到文件夹、置顶、分享和回收站都有，搜索在本地查标题和正文。
  • 设置里有「外观」（字体和字号）和「笔记库」两部分，笔记库里有「选择文件夹…」，说明文字写的是妙言读写这个文件夹里的 Markdown 文件，由 iCloud Drive 或你的网盘 App 与 Mac 保持同步。
  • 阅读视图能渲染表格、脚注、删除线和任务列表，用 highlight.js 高亮代码，能画 Mermaid 图，[[标题]] 双链会打开对应笔记。

4.5.0 版还缺两样，iPad 版没有自己的键盘快捷键，也不渲染 LaTeX 公式、PlantUML 或 Markmap，所以这些内容在 iPad 阅读视图里会显示成源码，虽然 Mac 版能渲染。需要在 iPad 上写公式的话，先拿一篇样例笔记试试。语法部分见 Markdown 语法速查与 GFM 差异和 Markdown 里写 LaTeX 公式。

iPad 怎么找到你的笔记

Mac 版读的是你在偏好设置里选的文件夹，iPad 版找资料库有两种方式。首次启动会检查 iCloud Drive，可用时就用应用自己的 iCloud Drive 文件夹，这个文件夹声明了对外可见，所以会以 MiaoYan 的名字出现在「文件」App 里。iCloud Drive 不可用，或者你想换一个，就点「选择文件夹」自己选，之后应用在那里读写普通文件。

同步链路因此很简单，Mac 把 .md 文件存进 iCloud Drive，iCloud 上传，iPad 看到文件出现就列出来。妙言自己不做同步，所以 Mac 上选的必须是 iPad 打开的同一个 iCloud Drive 文件夹，具体情况见跨设备同步 Markdown 笔记的几种做法。

还有一个细节，iPad 版会先读取 iCloud 报告的笔记目录，再读内容，首次启动时会显示「已找到 N 篇笔记…」，文件到齐之前，搜索里也会提示「还有 N 篇 iCloud 笔记在下载，同步完成后结果会更完整」。刚装完列表偏短，多半是这个原因，不是数据丢了。

另一台设备上看不到笔记时

按这个顺序排查。

  1. 确认 Mac 已经保存。 Mac 版在你停止输入大约一秒半后写文件，在访达里打开文件夹，确认 .md 文件在。
  2. 确认两边指向同一个文件夹。 Mac 上是偏好设置里的「笔记位置」，iPad 上是设置里的「笔记库」。任何一边选了别的文件夹，就是两个互不相干的资料库。
  3. 看同步状态。 iPad 版在设置的「笔记库」里会显示「同步中」「已同步」「离线」或「同步异常」，「离线」表示应用没连上它的 iCloud 容器，检查 iPad 上 iCloud Drive 是否开着。
  4. 等首次加载结束。 资料库大的时候，应用会写「正在从 iCloud 下载笔记，下次启动就会瞬间打开。」
  5. 在笔记列表上下拉刷新。 磁盘上有文件但列表里没有时用。
  6. 打开「文件」App。 笔记在 iCloud Drive 里能看到，问题在应用；看不到，问题在 iCloud。

同一篇笔记在两台设备上都改过，iPad 会弹出「这篇笔记已在别处更改」，选项是「重新加载」和「保留我的修改」，选「保留我的修改」会用你的文本覆盖另一个版本，拿不准就先看一眼另一个版本。Mac 版在收到外部改动时，会把未保存的文本备份到隐藏的 .miaoyan-conflicts 文件夹。

其他 iPad Markdown 编辑器

妙言只是其中一个选择，下面几个的说明取自它们各自的官网页面。

  • iA Writer 用纯文本加 Markdown 写作，可以切到带样式的预览，iPad 和 iPhone 版是买断，Mac 和 Windows 版有试用。
  • 1Writer 有行内预览和完整预览，可自定义额外键盘行，支持多窗口和拖放，能同步 Dropbox 和 WebDAV 文件夹以及 iCloud Drive。
  • Obsidian 移动端在编辑时底部有工具栏，下拉有快捷操作，它的帮助页说用法与桌面版相近。

这三个里，列出 Dropbox 和 WebDAV 文件夹的是 1Writer，笔记本来就放在 Obsidian 库里的话就选 Obsidian。笔记放在和 Mac 共用的文件夹里，在 iPad 上主要阅读和做短编辑，妙言比较合适。Mac 这一侧的选择见 Mac 上怎么选 Markdown 编辑器。

常见问题

Mac 和 iPad 能编辑同一批 Markdown 文件吗？

可以，前提是两边打开同一个 iCloud Drive 文件夹，换设备前让同步先跑完，也不要在两台设备上同时改同一篇。

妙言 iPad 版有加粗的快捷键吗？

4.5.0 版的 iPad 版没有自己的快捷键，Markdown 符号需要自己输入。

iPad 版要订阅吗？

官网写的是买断一次，没有订阅和内购，同一次购买覆盖 Mac、iPhone 和 iPad。

笔记存在应用里吗？

不在，它们是你选的文件夹里的 .md 文件，在「文件」App 里看得到。
