Mac 上怎么打开 .md 文件

笔记管理2026年10月19日约 7 分钟

.md 文件是用 Markdown 写的纯文本，所以 Mac 上任何文本编辑器都能打开。想看原始文字，在访达里右键文件，选「打开方式」再选「文本编辑」；想看渲染后的标题和列表，用 Markdown 应用或者 VS Code 的预览。经常要打开的话，通过「显示简介」把默认应用设一次，以后双击就行。用文本编辑有一个坑在保存上，处于多信息文本（富文本）模式的文件会存成 .rtf，不再是你一开始的 .md。

.md 文件里面是什么

Markdown 文件就是普通文本，用几个标点符号代替排版，# 是标题，- 是列表项，** 包起来的是加粗。里面没有藏任何东西，不嵌图片，也不像 .docx 那样是个二进制容器，所以每个编辑器都能打开，同一个文件在不同软件里看起来又不一样。什么是 Markdown那篇讲了这些符号，语法速查有带示例的完整清单。

.md 和 .markdown 是同一种格式的两种扩展名，前者常见得多，能处理其中一个的应用通常两个都能处理。

用指定应用打开一次

苹果的 Mac 使用手册列了四种用指定应用打开文件的方式，对 .md 都适用：

  1. 把文件拖到访达或程序坞里的应用图标上。
  2. 在访达里选中文件，选「文件 > 打开方式」，再选一个应用。
  3. 按住 Control 点按文件，选「打开方式」，再选一个应用。
  4. 先打开应用，再选「文件 > 打开」。

用文本编辑看原始文字

文本编辑是每台 Mac 自带的，文件怎么写它就怎么显示，# 和 ** 都在。有两个设置决定它用起来安不安全。

第一个是多信息文本，也就是富文本。苹果的文本编辑手册说，纯文本文稿没有格式选项，选「格式 > 制作纯文本」会去掉所有格式并存成 .txt 文件，「格式 > 制作多信息文本」则允许格式并存成 .rtf。讲格式的那页还提到，看不到工具栏时要选「格式 > 制作多信息文本」，所以你的 .md 文件上如果出现了格式工具栏，就是在多信息文本模式，Markdown 文件就是这样被转掉的。编辑之前先选「格式 > 制作纯文本」。

第二个是扩展名。在「文本编辑 > 设置 > 打开和保存」里有一项「给纯文本文件添加“.txt”扩展名」，苹果的说明是保存纯文本文件时始终使用 .txt 扩展名；同一个窗口的「新建文稿」里可以把默认格式设成纯文本。用文本编辑写 Markdown 之前两项都确认一下，笔记文件夹里堆满 .md.txt 文件，清起来很烦。

在访达里快速查看

选中文件按空格键。苹果的说明是不用打开文件就能看到里面有什么，访达窗口、桌面、邮件和信息里的项目都可以用。它只是预览，不能编辑，用来找到对的文件，再用真正的应用打开。

把某个应用设为默认

想让所有 .md 文件都用同一个应用打开，苹果称之为永久更改某类文件的打开应用：

  1. 在访达里选中一个 .md 文件，选「文件 > 显示简介」，或者按住 Control 点按再选「显示简介」。
  2. 在简介窗口里展开「打开方式」。
  3. 从弹出菜单里选应用，再点「全部更改」。

苹果的提醒值得重复一遍，只想让这一个文件用该应用打开的话，不要点「全部更改」，它会改掉同类型的所有文件，其他文件夹里的 Markdown 文件也包括在内。

看渲染后的样子

有两种选择覆盖大部分情况。

  • VS Code。 Visual Studio Code 开箱就支持 Markdown，文档里写了在代码和预览之间切换的命令，也有「Markdown: Open Preview to the Side」，把预览放在旁边，边写边更新，已经在用代码编辑器的话选它最顺手。
  • Markdown 应用。 为笔记设计的应用会把渲染结果和源码并排显示，妙言就是其中一个，Mac 上怎么选 Markdown 编辑器把它和 Typora、Obsidian、VS Code 做了对比。

妙言怎么打开 .md 文件

妙言 V4.5.0 在 Info.plist 里把自己声明为 Markdown 文件的编辑器，扩展名是 md 和 markdown，类型是 net.daringfireball.markdown，所以它会出现在「打开方式」和「显示简介」的「打开方式」菜单里。mdown、mkd 这些少见的扩展名它自己没有声明，这类文件会不会推荐给它，要看 Mac 上其他应用怎么声明。

在终端里也能看到这一点，mdls -name kMDItemContentType note.md 会打印 macOS 给这个文件认定的类型，.md 文件是 net.daringfireball.markdown，没有任何已装应用声明过的扩展名，得到的是一个以 dyn. 开头的值，装了妙言的 Mac 上 .mdown 和 .mkd 就是这样。open -a MiaoYan note.md 只用妙言打开这一个文件，不动默认设置，open -e note.md 则用文本编辑打开。

双击文件会进入应用里的「单独模式」，菜单项是「文件 > 单独模式」（⌘O），从这个菜单项选文件或文件夹也一样。笔记列表里显示和你打开的文件放在一起的其他文件，应用自己的提示说退出这个模式用 Command+Shift+W。

哪些邻居文件会出现取决于扩展名。V4.5.0 里列表只收以 md、markdown、txt 结尾的文件，代码按你写的大小写原样比较，所以 README.MD 不会被这次扫描匹配，如果大写扩展名的文件没有出现在邻居里，把它改成小写的 .md。读取文件夹时，妙言还会跳过 macOS 不认定为文本的文件和 100 MB 及以上的文件。

想把文件收进自己的笔记文件夹而不是原地浏览，用「文件 > 导入」，它接受文件和文件夹，会把 Markdown 文件复制进来。

乱码和编码

.md 是文本，文本也有编码，用旧编码存的文件，比如 GBK 的中文，在默认按 UTF-8 读的应用里可能是乱码。妙言先按 UTF-8 读，失败了就让系统检测编码再按检测结果读。文本编辑可以自己选，在「文本编辑 > 设置 > 打开和保存」里，「纯文本文件编码」的弹出菜单决定打开和保存纯文本时的默认编码。一个文件在某个应用里显示不对，先换个会检测编码的应用看，再决定要不要编辑保存，因为保存会按那个应用选的编码重写整个文件。

该用哪个

别人发来的文件，快速查看或文本编辑就够了，代码项目里的 README 放在 VS Code 里最自然，每天都读写的一整个笔记文件夹，把某个 Markdown 应用设成 .md 的默认应用。

常见问题

为什么我的 .md 文件用别的应用打开了？

别的应用登记过这个类型。用「显示简介」，在「打开方式」里选你的应用，再点「全部更改」。

Windows 或 Linux 能打开同一个文件吗？

可以，它是纯文本，任何编辑器都能打开，表格、任务列表这些扩展各家渲染器不一样，见 CommonMark 与 GFM 的区别。

.md 文件和 .txt 文件一样吗？

内容都是纯文本，扩展名告诉应用要不要按 Markdown 处理，妙言把两者连同 .markdown 都列出来。
