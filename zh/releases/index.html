V4.9.0 Barioth 2026-11-11

Mac

  1. 导出的 PDF 和预览保持一致，图片说明、引用和视频封面排版正常，深色模式下导出也是浅色页面，仓耳今楷的标题不再发糊，图表还没画完时不会把加载提示印进去
  2. 查找替换在新内容仍然匹配搜索词时会接着替换下一处，在 10 以上的有序列表项按 Tab，光标留在原来那一行
  3. 访达里的 .md 文件显示妙言的文档图标，预览里的引用排得更紧凑
  4. 妙言菜单和关于窗口里可以找到 iPhone 和 iPad 版，同一个 iCloud 云盘文件夹，在手机和平板上接着写

iPhone 和 iPad

  1. 阅读时可以直接勾选任务，从阅读进入编辑、写完回到阅读都停在原来的位置，标题多的笔记可以在菜单里打开目录，表格按笔记里写的方式对齐
  2. 编辑时菜单里可以插入照片、在笔记里查找、撤销和重做，回车会接着列表往下写，在空的列表项上再按一次回车结束列表
  3. 接上键盘后 Command-T 切换任务，Command-] 和 Command-[ 缩进整行，Tab 缩进列表项，有序列表下面也能正确嵌套
  4. 笔记可以复制一份，文件夹可以重命名，空文件夹可以删除，在文件 App 或分享菜单里选妙言就能打开 Markdown 文件
  5. 搜索按词匹配，标题里有的排在前面，新建笔记写到一半离开，下次新建时草稿还在，笔记库读不出来时列表保留原来的内容并可以重试
  6. 清空废纸篓只删除列表里看得到的笔记，正在写的笔记在别的设备上被改名、移走或删除时，刚写的内容会另存成一篇
