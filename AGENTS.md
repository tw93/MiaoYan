# MiaoYan Website Agent Guide

This is the website checkout on the `vercel` branch. The app source and its Xcode commands live on a different branch.

- `index.html`, `privacy.html`, `assets/`, and `data/` contain site content; `vercel.json` owns redirects.
- `scripts/build-site.py` generates the home pages from one copy table per language: `/` (English, the default) plus `/zh/`, `/tw/`, `/ja/`, `/ko/`, `/de/`, `/fr/` and `/es/`, the README's seven languages and the app's Spanish. Edit it and run `python3 -I scripts/build-site.py` instead of editing the generated `index.html` files; a copy change lands in every language in the same commit. The pages use `site.css`, whose type and tokens follow mole.fit (one serif face, Songti, Mincho or Myeongjo for CJK). The hero wordmark is near-black `MiaoYan 語` in every language, the family's one Traditional character per product (Mole 鼴, Kaku 書, Pake 殼, Hina 賞): 語 comes from the one-glyph `fonts/miaoyan-mark.woff2` that `scripts/build-fonts.py` cuts from Source Han Serif TC, with one small near-black dot circling it on its own upright orbit, counter-clockwise at mole.fit's quiet scale. Pages other than `/zh/` and `/tw/` show the English screenshots.
- The site recommends the App Store and links only to the App Store and the GitHub repository, never to a Mac download (maintainer, 2026-10-11). Store links carry `data-store`: iPhone and iPad get the region-less link, which opens the App Store app, the Mac gets `macappstore://`, and other devices keep the default, `/cn/` on the Chinese page because a desktop browser in China loses the app on the region-less link.
- `cats.html` now redirects to cats.tw93.fun (`vercel.json`) and its files are gone. `tailwind.css` and `build.css` stay only for the sponsors pipeline in `docs/sponsors-board.md`; no page loads them.
- `.vercelignore` keeps `AGENTS.md`, `docs/`, `data/` and `scripts/` out of the deployment, so they are not served. A new internal file goes there too.
- Google Analytics runs in consent mode with storage denied, so the site sets no cookies and needs no consent banner; `privacy.html` says so. Keep the two in step.
- `appcast.xml` and `Release/` are distribution surfaces. Changes need the actual published version, download, and artifact verified; do not infer release success from XML syntax alone.
- `npm run sponsors` invokes a network-backed generator, not a read-only verifier. Read its inputs and output paths before running it.
- Check local links for documentation edits and render affected pages for visual changes. Preserve unrelated site work and stable asset URLs.
