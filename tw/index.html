為什麼選擇妙言

本地

Markdown 檔案保存在你選擇的本地資料夾，不收集筆記資料。跨裝置時，可交給 iCloud 雲碟、堅果雲或你熟悉的檔案同步工具。

專注

三欄經典佈局將目錄、筆記與編輯器收斂一處。支援深色模式、無干擾寫作和常用快捷鍵，無需維護複雜外掛系統。

原生

使用 Swift 6 原生開發，不依賴 Electron。分欄模式提供即時預覽與 60fps 雙向捲動同步，絲滑跟手。

夠用

內建雙向連結與反向連結、LaTeX 公式、Mermaid 圖表、版本歷史、自動排版與命令列工具，也能一鍵開啟投影片簡報。

妙言適合誰

和 Typora 相比

妙言不做所見即所得編輯，而是保留純 Markdown 原始檔編輯與獨立預覽。更適合希望直接掌控原始檔，又需要即時預覽的人。

和 Obsidian 相比

妙言沒有 Electron 執行環境，也不以外掛生態為中心。更適合想要原生、輕量、純本地檔案和開箱即用核心功能的人。

常見問題

是買斷制還是訂閱制？

一次性買斷，終身使用，沒有訂閱或內購。同一次購買可在登入同一 Apple 帳號的 Mac、iPhone 和 iPad 上完整使用。

該裝哪個版本？

推薦 App Store 版，買一次 Mac、iPhone 和 iPad 都能用，打開的是同一個 iCloud 雲碟資料夾，更新也是自動的，Mac 版的原始碼開放在 GitHub。

筆記存在哪裡？

就在你選定的資料夾裡，每篇都是普通的 .md 檔案，妙言不收集筆記資料，以後換工具時整個資料夾帶走就行。

Mac 和手機之間怎麼同步？

把筆記資料夾放在 iCloud 雲碟裡，Mac、iPhone 和 iPad 打開的就是同一份筆記，Mac 上也可以用堅果雲等檔案同步工具。

支援哪些 Markdown 語法？

GitHub 風格的 Markdown，加上 LaTeX 公式、Mermaid、PlantUML 和 Markmap 圖表、雙向連結，以及用 --- 分頁的簡報模式。

需要什麼系統？

Mac 需要 macOS 12 以上，iPhone 和 iPad 需要 iOS 18 以上。
